# Oracle SQL Interview Practice

Structured Oracle SQL practice from **Beginner → Intermediate → Advanced → Real-World → Mixed Interview Scenarios**.

## Repository map

- `01_Beginner` — SELECT, WHERE, sorting, filtering, aggregates
- `02_Intermediate` — joins, subqueries, functions, set operators, CTEs
- `03_Advanced` — analytical/window functions, PIVOT/UNPIVOT, hierarchical SQL
- `04_Real_World` — banking/AML, data quality, data engineering scenarios
- `05_Interview_Mixed` — interview-style scenario problems

## Practice workflow

1. Open a `.sql` file.
2. Read the question.
3. Write your solution under `-- Write your Oracle SQL solution below`.
4. Test it in Oracle.
5. Save with `Ctrl + S`.
6. Upload your work:

```powershell
git upload
```

## Core schema

Beginner/intermediate questions commonly assume Oracle's classic `EMP` and `DEPT` tables. Real-world scenarios contain suggested table names and should be adapted to your schema.

## Git workflow

```text
Write SQL → Save → git upload → GitHub
```
